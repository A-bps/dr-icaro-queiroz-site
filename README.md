# Dr. Ícaro Queiroz — site (reengenharia)

Site estático do Dr. Ícaro Queiroz, Transplante Capilar e Tricologia em São José do Rio Preto/SP. Conteúdo e imagens vêm do site oficial (dricaroqueiroz.com).

- Sem build: HTML, CSS e JS puros. GSAP + ScrollTrigger e Lenis via CDN (jsDelivr).
- Páginas: `index.html`, `resultados.html`, `duvidas.html`, `pre-avaliacao.html`.
- `css/`: `tokens.css` (cores, tipo, espaço), `base.css`, `layout.css`, `components.css`.
- `js/`: `nav.js`, `motion.js`, `counters.js`, `compare.js`, `video.js`, `quiz.js`.
- `docs/`: inventário de conteúdo, análise do site original e direção de arte.

Rodar localmente: `npx serve .` e abrir o endereço indicado.

Publicado em https://a-bps.github.io/dr-icaro-queiroz-site/
